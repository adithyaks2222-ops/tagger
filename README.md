# 📍 TAGGER

### GPS Location Image Generator

**TAGGER** is a web-based tool that allows users to add professional GPS-style location information to their photographs.

Upload an image, enter location details, coordinates, date and time, and instantly generate a customized geotag overlay. The final image can then be downloaded directly from the browser.

🔗 **Live Demo:** https://adithyaks2222-ops.github.io/tagger/

---

## ✨ Features

- 🖼️ Upload custom images
- 📍 Add location titles
- 🏠 Add full location addresses
- 🌐 Enter latitude and longitude coordinates
- 🗺️ Dynamic satellite map preview
- 📌 GPS location pin overlay
- 🕒 Custom date and time information
- 👀 Real-time image preview
- 📥 Download generated images
- 🎨 Modern GPS Map Camera-inspired interface

## ⚙️ How It Works

### 1. Upload an Image

Upload any image from your device. The image is instantly displayed in the live preview area.

### 2. Add Location Information

Customize the GPS metadata including:

- Location title
- Full address
- Latitude
- Longitude
- Date and time

### 3. Dynamic Map Generation

When valid latitude and longitude coordinates are provided, TAGGER dynamically updates the satellite map preview based on the selected location.

### 4. Live Preview

All information updates instantly, allowing users to see the final composition before downloading.

### 5. Download

The completed image is generated directly in the browser and downloaded as a high-quality image.
